CardScanR Support

Help for CardScanR: TCG Card Scanner (com.cardscanr.app).

Contact

CardScanR is operated by Andrew Gore.

Email: cardscanr.dev@gmail.com

Email support

Use this address for general support, privacy enquiries, sign-in help, sync help, and account or data deletion requests. No web form is offered because this static site has no backend.

What to include

  • App name: CardScanR: TCG Card Scanner
  • Android package: com.cardscanr.app
  • App version from Settings → About (version name and version code if shown)
  • Device model and Android version
  • Whether you use Google or email sign-in
  • A clear description of the issue and steps to reproduce
  • Screenshots if helpful (avoid including personal photos unrelated to the issue)
Privacy warning.

Do not email passwords, payment card details, one-time codes, recovery keys, or other sensitive secrets. If you export a diagnostics bundle, review it before sharing — diagnostics may include scan evidence, pricing status, and device-local logs.

Sign-in help

  • Confirm you are using the Play / release package com.cardscanr.app.
  • After Google sign-in in the browser, return to the app. If the app does not open, use the OAuth return page deep link cardscanr://login-callback or reopen CardScanR and try again.
  • For email sign-in, check spam for verification mail from the auth provider and confirm the email address is typed correctly.
  • If stuck on a browser page, see Sign-in return.

Cloud sync help

  • Collection data stays on-device until you explicitly opt in to cloud sync while signed in.
  • Sync uploads collection metadata — it does not upload card photographs from your camera.
  • If sync fails, note whether you are signed in, whether sync is enabled in Settings, and the app version from About, then email support.

Account deletion

See Delete Account and Data for in-app paths, email requests, and what is deleted versus retained. Sign out does not delete the account or remove local collection data.
