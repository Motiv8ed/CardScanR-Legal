Contact

CardScanR is operated by Andrew Gore.

Email: cardscanr.dev@gmail.com

Email support

Use this address for general support, privacy enquiries, and account or data deletion requests. No web form is offered because this static site has no backend.

What to include

  • App name: CardScanR: TCG Card Scanner
  • Android package: com.cardscanr.app
  • App version shown in Settings → About
  • Device model and Android version
  • Whether you use Google or email sign-in
  • A clear description of the issue and steps to reproduce
  • Screenshots if helpful (avoid including personal photos unrelated to the issue)
Privacy warning.

Do not email passwords, payment card details, one-time codes, recovery keys, or other sensitive secrets. If you export a diagnostics bundle, review it before sharing — diagnostics may include scan evidence, pricing status, and device-local logs.

Account deletion

To request account and cloud data deletion, use the Delete Account and Data page or email cardscanr.dev@gmail.com.
